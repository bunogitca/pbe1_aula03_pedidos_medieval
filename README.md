# Pedidos medievais
Projeto full stack criado em aula de back end

## Tecnologias
- Node.js
- Vscode
- JavaScript
- JSON
- HTML

## Como testar
- 1 clonar o repositório
- Abrir com o VsCode e em um terminal digitar s seguintes comandos
- ```bash
  npm install
  npm run dev
  ```

  - Executar o arquivo cliente/index.html com live server do VsCode.
