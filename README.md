# Medieval Orders
Full-stack project created during a back-end class

## Technologies
- Node.js
- VS Code
- JavaScript
- JSON
- HTML

## How to test
- Clone the repository
- Open it in VS Code and enter the following commands in the terminal:
- ```bash
  npm install
  npm run dev
  ```

- Run the `cliente/index.html` file using the VS Code Live Server extension.
